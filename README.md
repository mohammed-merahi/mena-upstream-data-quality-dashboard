# MENA Upstream Data Quality Dashboard

A Streamlit-based application for monitoring and reporting data quality issues in upstream oil & gas datasets.

## Overview

This application validates well data and identifies common data-quality issues that impact operational reporting and decision-making.

## Features

- Data Quality Score
- Executive Summary
- Severity Classification
- Well Data Validation Rules
- Interactive Dashboard
- CSV Export
- Excel Export
- Issue Breakdown Visualization

## Validation Rules

- Missing Spud Date
- Missing Completion Date
- Missing Operator
- Duplicate Wells
- Invalid Status
- Future Spud Date
- Missing Depth
- Invalid Depth

## Technology Stack

- Python
- Pandas
- Streamlit
- Plotly
- OpenPyXL

## Dashboard

### Key Metrics

- Quality Score
- Total Issues
- Records Analyzed
- Critical / High / Medium Issues

### Reporting

- Issue Breakdown Chart
- Issue Detail Table
- CSV Export
- Excel Export

## Use Case

Designed to support upstream data management, drilling operations reporting, and data governance initiatives.
