# MENA Well Data Quality Monitor

A Python application that validates upstream oil and gas well data and identifies common data quality issues.

## Business Problem

Well databases often contain:

- Missing values
- Duplicate wells
- Invalid statuses
- Incorrect dates

Poor data quality impacts reporting, planning, and operational decision-making.

## Solution

This application automatically analyzes well datasets and generates quality reports.

## Features

- Missing value detection
- Duplicate well detection
- Future date validation
- Invalid status validation
- Data quality metrics
- Dashboard reporting

## Technology Stack

- Python
- Pandas
- Streamlit
- Plotly
